Section A — daily

One x-axis slot per calendar day, 1 Oct – 11 Nov 2026. Days with no published figure stay empty.

Section B — weekly

Weeks run Monday–Sunday. Crowd size shows the peak day; arrests and injuries are summed. * marks weeks clipped by the window.

Section C — cross-episode, one panel per movement

Seven episodes, four series each. Every series is indexed to its own first comparable published figure (index = 100, dashed grey reference line), so protestors in the hundred-thousands and arrests in the thousands share one axis. Panel position encodes the episode; hue encodes the series, identically in all panels. Hollow markers = regional, partial, derived or actions-total figures. Hover a series (or the legend) to trace it across all seven panels.

x — whole weeks since each movement's first action, true scale, so durations differ (Nahel 2 weeks, Gilets jaunes 44). y — index, log scale, 0.1–1,500 shared by every panel. Dashed segment = at least one week with no published figure lies between the two points. "obs" under each strip = number of weeks with a figure for protestors · arrests · forces injured · protestors injured.

Section C′ — cross-episode, transposed

The same data with the comparison axis flipped: one panel per series, one line per movement. Colour encodes the movement on a single sequential ramp, light → dark in the same order in every panel, so the reader learns the ramp once. Use this to ask "did arrests behave the same way in every episode?".

y limits are per panel — a log range printed under each strip — because the series span different orders of magnitude. Only the protestor panel and the forces-injured panel contain enough points to read as a shape; the sparse panels are the finding, not a defect.
